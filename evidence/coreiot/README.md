# Lưu minh chứng CoreIOT đã chạy

Ảnh hiện có trong cuộc trò chuyện; cần lưu tệp vào thư mục này để nhúng vào PDF.

Tên gợi ý:

- `dashboard.png`: hai biểu đồ và switch Fan trên dashboard đang dùng.
- `root_rulechain.png`: nhánh Post telemetry qua filter SmartRoom.
- `smartroom_rulechain.png`: các node tạo/xóa alarm.
- `alarm.png`: SmartRoom Environment, Major, originator room-node-01.
- `notifications.png`: thông báo New alarm và Alarm cleared.

Export cấu hình từ tài khoản đang dùng và lưu:

- `dashboard.verified.json`.
- `root_rulechain.verified.json`.
- `smartroom_rulechain.verified.json`.

Đây là minh chứng phần cloud với nguồn cảm biến `simulation`, không phải ảnh hoặc số đo phần cứng. Notification trên tài khoản đã hoạt động; không cần tạo thêm rule trùng lặp. Khi các tệp có sẵn, cập nhật báo cáo để chèn ảnh và đối chiếu đúng URL/ID dashboard hiện tại.
