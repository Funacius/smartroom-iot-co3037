2. General Requirements
The project focuses on sensing and connectivity technologies built on the CoreIOT
platform and the ESP32-S3 (YoloUNO) development board. Students are encouraged to
study and extend the sample projects presented on CoreIOT; in that case, the report must
clearly state which parts are reused and which parts were developed by the group.
The system must integrate multiple devices operating together. Groups may choose one
of the following two connection models, or combine both:
• Direct connection model: each device connects and sends its data independently to
the CoreIOT server; smart features are implemented using RuleChain.
• IoT Gateway model: devices connect to a device acting as an IoT Gateway that
aggregates the data; the Gateway then forwards the data to the CoreIOT server.
The system features must be described in detail in the Introduction section of the report.
When analyzing and selecting implementation technologies, groups must map each
feature to the list of technology elements in Section 3 (using codes T01–T15, N01–N07).
If a technology outside the list is used, the group must describe it in the system analysis
section.

3.4. Score Calculation
Project score = min(8; Σ Technology) + Report (≤2) + min(1; Σ Advanced),
maximum 10 points
• An element earns points only if evidence (screenshots, logs, video, source code) is
provided in the report.
• A partially implemented element will be graded by the lecturer according to its level
of completion.
• Individual scores may be adjusted based on the task assignment table, each member's
contribution and the oral examination during the presentation session.

6. General Rules
• All referenced documents, source code and sample projects must be properly cited.
Copying reports or source code between groups will be handled according to the
University's academic integrity regulations.
• Groups may use AI tools to assist with programming and writing, but must clearly
state the extent of such use in the report; each member must be able to explain their
own part of the work during the oral examination.
• Late submission: points may be deducted according to the number of days late
• For questions about the project, students should contact the lecturer by email or via
the course forum on LMS.
